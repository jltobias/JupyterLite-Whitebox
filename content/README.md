# JupyterLite Whitebox notebooks

Start with **00_Welcome.ipynb**, then open **01_Architecture_and_Compatibility.ipynb** before the category chapters.

## Chapters

- 02 Data Tools
- 03 GIS Analysis
- 04 Hydrological Analysis
- 05 Image Analysis
- 06 LiDAR Analysis
- 07 Mathematical & Statistical Analysis
- 08 Stream Network Analysis
- 09 Terrain Analysis
- 10 API Catalog

These notebooks teach the `whitebox` Python API in-browser. Native WhiteboxTools analysis requires a standard Python kernel because JupyterLite runs in WebAssembly and cannot launch the WhiteboxTools executable.
